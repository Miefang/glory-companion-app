# 荣耀伴学 App

荣耀伴学是面向初中托管与自习场景的学习辅助 App。产品以学生的作业、练习和阶段性测评为数据入口，帮助识别错题与薄弱知识点，并为复习、预习和家长反馈提供依据。

## 当前产品重点

首期围绕一条可验证的闭环建设：

`拍照上传作业 -> AI 识别与初步分析 -> 错题归因 -> 关联知识点 -> 更新学生知识图谱`

首期优先验证：

- 平板拍照上传作业、练习和试卷
- AI 识别题目、作答和正确答案
- 错题分析：错因、涉及知识点、解题思路
- 学生个人知识点掌握档案
- 基于薄弱知识点的复习、练习和预习建议
- 学生、老师、家长可理解的学习反馈

## 项目状态

当前阶段：需求对齐与首期原型准备。

开发前需要确认首发年级、科目、题型范围、平板设备形态和首期验收标准。
