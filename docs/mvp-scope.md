# 首期范围与待确认事项

## 建议首期闭环

```text
学生登录
  -> 拍照上传作业或试卷
  -> AI 识别题目和作答
  -> 对错与错因分析
  -> 关联教材知识点
  -> 更新个人知识点档案
  -> 输出复习/练习建议
  -> 老师复核并形成反馈
```

## 首期必须验证的能力

| 能力 | 验证结果 |
| --- | --- |
| 平板拍照清晰度、裁切和上传 | 待验证 |
| 中文手写与数学公式识别 | 待验证 |
| 题目、答案和知识点关联 | 待验证 |
| 错因分析是否可解释 | 待验证 |
| 老师复核流程是否省时 | 待验证 |
| 学生能否根据结果完成订正 | 待验证 |
| 家长是否能看懂报告 | 待验证 |

## 暂不作为首期承诺

- 覆盖所有学科和所有题型
- 全自动批改，不需要老师复核
- 对作文、开放题和复杂证明题给出稳定结论
- 承诺提分或预测学生能力
- 摄像头识别专注度、情绪或心理状态
- 公开排名、扣分或按成绩比较学生
- 复杂知识图谱可视化和完整激励体系

## 开发前需要拍板

1. 首发年级和首发科目
2. 首期支持的题型与拍照页数
3. 平板设备型号和是否统一配发
4. 老师复核是否为家长反馈的前置条件
5. 学生端、老师端、家长端的形态
6. 首期试点班级和学生数量
7. 首期验收样本与可接受的识别/分析错误范围
