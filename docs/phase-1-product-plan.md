# 一期产品企划：荣耀伴学平板原型

## 一期目标

先验证学生在横屏平板上的核心使用路径：

`登录 -> 首页 -> 拍照上传 / 查看知识图谱`

首页只保留两个核心任务入口：

1. 拍照上传：把作业、练习和试卷带入系统。
2. 知识图谱：查看个人知识点掌握情况，识别下一步需要巩固的内容。

其他模块使用“口口口”占位，避免一期原型把尚未确认的功能做成既定承诺。

## 页面结构

### 登录页

- 左侧：品牌、学习主张、轻量知识节点视觉
- 右侧：账号、密码、记住账号、忘记密码、登录
- 登录校验：账号或密码为空时展示字段错误
- 原型状态：任意非空账号和密码即可进入首页

### 首页

- 左侧固定导航：首页、我的知识图谱、二期占位、三期占位
- 顶部：自习模式、日期、通知、学生账号
- 主区域：问候语和两张核心功能入口卡
- 下方：今日学习焦点摘要，以及一个后续功能占位区
- 拍照上传：弹出照片选择态，模拟提交分析

### 个人页 / 学生知识图谱

- 学生摘要：年级、班级、学习天数、知识点统计
- 学科筛选：全部、数学、英语、物理
- 知识地图：中心节点 + 学科知识点节点
- 节点状态：已掌握、巩固中、待加强
- 点击节点：右侧展示知识点说明、掌握进度、数据来源和后续动作占位

## 视觉方向

- 参考作业辅导产品的亲和、明快和低门槛特征，采用蓝色作为主色
- 用青绿、橙色、紫色区分学习状态，不让信息只依赖颜色表达
- 以 1280×800 以上横屏平板作为主设计基准
- 页面保持大点击区域、少层级入口、短文案和高可见状态
- 卡片圆角控制在 8px 左右，保持产品化而不是营销页风格

## 本期暂不定稿

- 真实账号体系与教务登录方式
- 拍照后的裁切、重拍、科目选择和批改等待状态
- 知识点来源、教材版本和学科覆盖
- AI 结果是否必须经过老师复核后才能展示
- 老师端、家长端和班级大屏的页面结构
- 二期预习、复习、错题本、讲解和报告功能的具体优先级
